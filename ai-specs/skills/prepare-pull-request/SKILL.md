# prepare-pull-request

1. Revisar status, diff y cambio OpenSpec; excluir secretos y trabajo ajeno.
2. Comprobar tareas y evidencia con verify-change y revisión adversarial.
3. Describir problema, comportamiento final, validación y riesgos concretos.
4. Mantener commits locales pequeños y registrar pasos de reversión.
5. Crear o publicar un PR solo cuando esté autorizado; conservar el enlace si se crea.
6. Archivar OpenSpec después de integrar y sincronizar las especificaciones.
