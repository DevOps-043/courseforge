## Validación de este corte

5 pruebas controller de paneles, 1 routing del capture timeline, 4 policy de paleta y 5 foco/cursor = 15 pruebas dirigidas aprobadas; TypeScript focalizado/web y diff sin errores. Controller prueba primera opción, skip disabled/hidden, wrap, Tab endpoints, cierre/cancel policy, no robo de foco y desmontaje. El routing ejecuta código del handler real, pero el selector/DOM es un fake: no acredita renderizado React ni Chrome. No browser smoke, QA formal, render ni migración ejecutados.
