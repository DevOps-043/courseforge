# Estándares base

Estado: vigente. Actualizado: 2026-10-15.

- Una unidad pequeña y verificable a la vez; especificar antes de cambiar contratos.
- Leer AGENTS.md, contexto, dominio y cambio activo antes de editar.
- Conservar trabajo ajeno y usar ramas/worktrees recuperables para cambios materiales.
- No confundir instrucciones del modelo con autorización ejecutable.
- Mantener identidad, organización, validación y permisos en servidor.
- Nunca copiar credenciales, .env, configuraciones personales ni datos de producción.
- No conceder shell, Git o skills de desarrollo a los agentes runtime.
- Exigir autorización para publicación, despliegue, envíos y mutaciones destructivas.
- Documentar fallos, límites y resultados reales; no ocultar deuda para obtener verde.
- Mantener estándares extensos en engineering-practices.md y contratos en su dominio.
- El código es evidencia; las afirmaciones históricas no sustituyen inspección actual.
- No se promete una capacidad de carga por una cifra genérica de un prompt:
  cualquier objetivo necesita SLO y prueba de carga reproducible.
