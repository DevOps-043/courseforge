# Diseño

La respuesta compacta conserva `operations` y `summary`. Una lista vacía es una
respuesta conversacional del chat. Una lista no vacía pasa por el catálogo de
permisos, el contrato del editor y la simulación existente. El chat reenvía hasta
cuatro mensajes recientes como contexto no confiable. El servidor proyecta
capacidades y valores de edición sobre la versión guardada de la composición.

Para revertir el cambio, retirar el turno conversacional y las nuevas entradas
del catálogo. Las operaciones producen documentos mediante contratos existentes
y no requieren migración.
