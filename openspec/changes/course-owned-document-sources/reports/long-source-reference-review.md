# Revisión del documento de referencia para talleres largos

Se inspeccionó localmente un TXT institucional de 539,081 bytes, diez capítulos principales y 530,704 unidades UTF-16 después de normalizar. Incluye identidad, posicionamiento, arquitectura de marca, límites de afirmaciones y gobernanza. En la revisión textual se buscaron URLs con protocolo, prefijos `www`, dominios habituales sin protocolo, enlaces Markdown e indicadores bibliográficos. No se detectaron referencias web explícitas ni bibliografía. Las menciones de fuentes y referencias observadas describen reglas de documentación, evidencias institucionales o remisiones internas. La inspección no establece el origen histórico de todas las afirmaciones.

En una prueba local se usó el extractor con un presupuesto de diagnóstico para medir el texto sin cambiar la configuración del producto. El fragmentador produjo 266 fragmentos y el planificador actual de Base los distribuyó en 23 lotes con un propósito de prueba sobre gobernanza de marca. Se verificó que el plan incluyera exactamente todos los identificadores en el orden de extracción. El lote mayor reservó 34,543 de las 36,000 unidades estimadas permitidas y el plan total reservó 767,661. Son estimaciones del planificador y no un recuento de tokens del proveedor.

No hubo llamadas de IA, lecturas web del contenido ni cambios al original. El ensayo comprueba planificación, no admisión ni generación. El original excede el límite de extracción y el almacenamiento de 128 fragmentos por versión, y Temario y Plan todavía tienen el límite de contexto directo de 120,000. La revisión documental y la preparación de Materiales también requieren eliminar lecturas globales antes de ampliar el tamaño típico de los cursos.
