# Capas visuales adicionales

El editor conserva los planos base 0–10 y las profundidades predeterminadas.
El usuario puede registrar planos extra, asignar clips y quitar esos planos sin
renumerar otros. Una capa ocupada requiere dos confirmaciones y una lista exacta
de clips confirmados; pistas bloqueadas impiden eliminarla. Los assets originales
permanecen intactos. No hay despliegue, SQL remoto ni cambios de proveedor.
