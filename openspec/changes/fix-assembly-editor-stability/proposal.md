# Estabilidad de ensamble y vínculos editoriales

El aviso de Academy ocupa el monitor y las actualizaciones del listado desmontan el editor. El preview del borrador de prueba responde INVALID_REQUEST porque sus imágenes editoriales no están vinculadas al borrador.

Se retira el aviso de Ensamble, se conserva el editor durante actualizaciones y errores del listado, y se recuperan vínculos de imágenes exclusivamente desde el artefacto generado verificado. No cambia el documento, motion, recorrido, fuentes ni proveedores. Se valida localmente y se sube a staging con la cuenta solicitada para revisar el flujo real, sin generación pagada ni HeyGen.
