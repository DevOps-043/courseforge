## ADDED Requirements

### Requirement: Historial visible de versiones

El historial de Entrega SHALL abrir como diálogo modal por encima del editor.

#### Scenario: Abrir desde la biblioteca

- **WHEN** el usuario activa Versiones dentro de Entrega
- **THEN** el diálogo permanece dentro del viewport y por encima del timeline
- **AND** la lista larga se desplaza dentro del diálogo
- **AND** cerrar con Escape devuelve el foco al botón Versiones
