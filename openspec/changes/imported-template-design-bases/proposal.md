# Bases importadas para crear plantillas

El usuario aclara que importar debe alimentar las bases generales del estudio de plantillas, además de permitir usar el paquete en un deck. Crear desde una base debe producir una plantilla independiente y editable por conversación, sin volver al catálogo hardcodeado.

Añadir selección de bases de la organización, fork explícito y referencia inmutable al run de origen. El estudio importado muestra el HTML real, permite seleccionar diseños y revisar textos/estilos con IA mediante parches validados. Conservar la base y sus recursos privados; no implica distribución entre organizaciones ni conversión al editor geométrico.
