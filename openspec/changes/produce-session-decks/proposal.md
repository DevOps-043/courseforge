# Producir presentaciones de sesiones desde Producción

La revisión síncrona muestra contenido como texto pero no produce un deck visual. Reutilizar el renderer, contrato visual y QA de las presentaciones Academy para producir y recuperar un asset por sesión aprobada, dentro del mismo paso.

Se conserva la autoría, aprobación y separación de audiencias. No se generan videos, imágenes pagadas ni contenido con IA. No se despliega ni se modifica el esquema remoto.
