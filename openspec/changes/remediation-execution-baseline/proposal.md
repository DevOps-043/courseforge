# Base de ejecución de remediación

## Why
La auditoría tiene resultados históricos y cambios documentales pendientes. F0.1
necesita evidencia fresca antes de intervenir autorización o configuración.

## What Changes
- Registrar HEAD, runtime, lockfile y cambios heredados sin modificarlos.
- Reproducir gate, tipos y grafo con dependencias instaladas, sin reinstalación.
- Conservar mapa de comandos y continuidad para F1.1.

## Impact
Solo documentación y evidencia local. Sin cambios de producto, SQL o despliegue.
